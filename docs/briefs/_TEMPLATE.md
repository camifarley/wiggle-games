# NN · Game Title  (icon)

> Copy this file to `docs/briefs/NN-name.md`. Short answers are fine; skip what doesn't apply.
> This repo is public: no child names or personal details.

## 1. The fantasy (one line)
What the kid *gets to be or do* that's impossible in real life. "You're a slime wizard."

## 2. Core verbs: body → effect
| Body move | What happens on screen | Sound | Voice line |
|---|---|---|---|
| | | | |

Every input needs a **big, visible reaction**. Movement that does nothing is a bug.

## 3. Signature moment
The one moment kids will want to repeat and show a grown-up. Design everything to lead up to it.

## 4. Build-up → release
How waiting or collecting makes the payoff bigger (kids invent "wait, then explode" strategies, so reward them).

## 5. Energy pacing: crazy ↔ sneaky
Alternate high-energy bursts with calm or sneaky challenges. Say how the game switches between them
and what triggers each.

## 6. Session arc (1–5 minutes)
- **0:00–0:30 Hook:** instant fun, zero instructions needed
- **0:30–2:00 Grow:** new things unlock, numbers climb
- **2:00–4:00 Twist:** a surprise mechanic or character
- **4:00+ Finale:** a huge celebration, then free play continues (no game over)

## 7. Absence & surprise inputs
What happens if the kid hides their face, leaves the frame, spins, or freezes? (Peekaboo is always funny.)

## 8. No-fail rule
What would be a "mistake" in a grown-up game, and how is it funny or rewarding here instead?

## 9. Numbers & progress
Score, levels, counters. Big, fast-climbing numbers that a kid who reads numbers can follow.

## 10. Tech
- `needs`: (motion / color / face / hands / pose) and why
- Performance budget per tier (object caps, effects)
- Fallback if detection is flaky (for example a big on-screen button)
- **Core additions** this game needs (keep them additive and reusable)
- How to test with `?fakecam&debug` (debug keys to simulate gestures)

## 11. Safety & setup
Space needed, device placement, dizziness or overexcitement limits.

## 12. Playtest questions
What should the parent watch for? What would turn a 3/5 into a 5/5?
